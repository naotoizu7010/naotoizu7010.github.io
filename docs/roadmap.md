# Portfolio Roadmap

## Current Status

- 暫定Astro版を本番公開済み。
- トップページは、一般向けに人柄と活動を伝えるための暫定版。
- 研究者向けの硬い情報は、トップとは分けて `/researcher` に整理する方針。
- 大きなリデザインや情報設計の変更は、暫定公開版を壊さないように別PRで進める。

## Direction

- まずは暫定公開版を安定させる。
- 一般向けトップと研究者向けページを分ける。
- 既存URLはなるべく維持する。
- 変更の粒度は小さめにし、デザイン改善、コンテンツ追加、URL対応を分けて進める。
